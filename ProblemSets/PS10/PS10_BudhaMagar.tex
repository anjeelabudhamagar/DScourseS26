\section*{Best Performing Model}

The decision tree model achieved the highest test accuracy (0.868), making it the best-performing model in this comparison. The K-Nearest Neighbors model had the lowest test accuracy (0.843).

The Support Vector Machine (0.860) and Neural Network (0.858) performed very similarly. The Logistic Regression (LASSO) model achieved an accuracy of 0.853, which is slightly lower but still competitive compared to the other models.

Overall, the performance differences across models are relatively small, suggesting that multiple classification methods perform reasonably well on this dataset.
